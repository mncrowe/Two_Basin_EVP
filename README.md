# Two Basin EVP

This repository contains MATLAB code for solving the two-basin shallow water eigenvalue problem using spectral methods (collocation). Files are currently setup to run on Windows, however should also run on Linux once the filepaths are updated (swapping \ for /).

For full functionality, [ffmpeg](https://ffmpeg.org/) should be installed and added to the system path. Without this, the code will run but will not produce the output as mp4 files.

This code can also solve the N-basin problem by changing the parameter `N`.
